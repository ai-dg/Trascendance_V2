🐛 Debug - Overlay "Ready to play?"

🔍 Instructions de debug

Pour déboguer le problème :
1. Ouvrez la console du navigateur (F12 → Console)
2. Allez sur http://localhost:3000
3. Connectez-vous et lancez le jeu
4. Cliquez sur "START GAME"
5. Regardez les logs dans la console

📊 Logs attendus

Si tout fonctionne, vous devriez voir :
startGame() called
GameManager exists, calling startGame()
GameManager.startGame() called
Game state after start: {player1Score: 0, player2Score: 0, gameRunning: true, winner: null}
notifyListeners called, listeners count: 1
updateGameState called with: {player1Score: 0, player2Score: 0, gameRunning: true, winner: null}
Found overlays: {gameOverOverlay: div, startOverlay: div}

🚨 Problèmes possibles

Si vous voyez "GameManager is null!":
- Le canvas n'est pas correctement initialisé
- Problème dans la méthode render() de GamePage
Si vous ne voyez pas "updateGameState called":
- Les listeners ne sont pas correctement configurés
- Problème dans setupGameListeners()
Si vous voyez "Found overlays: {gameOverOverlay: null, startOverlay: null}":
- Les sélecteurs CSS ne trouvent pas les overlays
- Problème avec les attributs data-overlay

🔧 Solutions possibles

Si GameManager est null :
- Vérifier que this.canvas existe avant de créer GameManager
- Ajouter des logs dans la méthode render() de GamePage
Si les listeners ne fonctionnent pas :
- Vérifier que setupGameListeners() est appelé après la création du GameManager
- Vérifier que addListener() fonctionne correctement
Si les overlays ne sont pas trouvés :
- Vérifier que les attributs data-overlay sont correctement définis
- Utiliser des sélecteurs CSS plus spécifiques
